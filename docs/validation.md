## 本次新增验收

**用户范围**：真实 JSON 输出核对 `scope`、`viewer_uid` 和所有返回行的 UID，非 root 不含未知 owner 或其他 UID。核心测试验证当前 UID 可见、其他 UID/未知 owner 不可见，以及 viewer=0 的全用户判定。列表投影由交互、文本与 JSON 共用。

**多核与历史**：真实读取 `/proc/stat` 的总 CPU 和每核 ticks，忙循环后验证差分有效且在 0–100% 内。测试 History 的值、240 帧回绕、缺失帧留空、PID 同号但 start ticks 不同的隔离、旧进程淘汰以及独立刻度支持超过 100% 的进程 CPU。

**实际图表变化**：启动独立 Python 监听服务，先采集空闲曲线，再触碰 48 MiB 分配并执行 CPU 忙/闲循环。核对实际 RSS 增长至少 40 MiB、标题的进程 CPU 大于 0，并确认进程 CPU 曲线离开底部。验证 g 切换独立/整机刻度、c 翻页逻辑核，以及 80 × 24 压缩布局仍包含双图和进程详情。图表测试基于解析后的 VT 屏幕，不把数字标题变化独自当作曲线验收。

**安装升级**：在 `build/` 下创建独立 HOME、带空格的 Git checkout 和本地 bare remote。验证默认安装到用户 `.local/bin`，升级助手真实执行快进、重建并切换程序版本；随后提交故意不能编译的版本，确认已安装程序哈希不变；对脏工作区拒绝升级；修复上游后再次升级成功。测试非法参数、空或根目录前缀、缺编译器、修改文件后拒绝卸载、正常卸载及保留无关文件。完整诊断保存在 `build/install-test.log`，不访问 GitHub 或改动真实用户安装。

## 既有行为回归

通过 IPv4/IPv6 TCP/UDP、共享 socket 拥有者、重复 FD 去重、启动参数/PPID/CWD、筛选与排序、JSON、参数错误和 `--all` 状态差异检查。

终止操作覆盖默认小写 k、Cancel 焦点、TERM/KILL 确认、长命令滚动、窗口过小时禁止隐藏确认，以及自身/PID 1/自身祖先保护。真实父子树的后代身份被篡改时，所有目标预检失败且均存活；恢复身份后正常发送并回收退出状态。

监督链测试先仅终止 service，确认 supervisor 重新创建新 PID；再选择 supervisor 子树，确认无端口工作进程一并退出，launcher 和兄弟服务继续存活；显式终止 launcher 子树后剩余服务退出。

保留暂停后 0.4 秒无输出、正常采样 0.4 秒无全屏清除序列、确认弹窗冻结，以及关闭选中项前面 5 个端口后仍保持选中对象和屏幕行的检查。退出、SIGTERM、Ctrl-C、挂起/继续均验证 termios 恢复。

## 人工观察和边界

在本机 tmux 的 130 × 36 窗口观察系统 CPU、内存、每核仪表及真实服务的选中曲线布局。该观察不代表所有终端模拟器或长时间零闪烁承诺。独立曲线刻度会在历史峰值改变时调整，图例同时更新；进程热退出、排序值和窗口尺寸改变也可能导致必要布局变化。

本机 sudo 需要交互认证，因此未执行真实 sudo 全用户采集和系统级安装；root 范围判定由纯 UID 测试覆盖，用户安装/升级实际执行。没有声称绕过 namespace、LSM 或 proc 权限。未执行 GitHub 网络升级，已执行隔离本地 remote 的真实 Git 快进流程。

未做大规模容量、长期稳定性、CPU 热插拔实机、无 IPv6、无 pidfd 内核或权限矩阵验收。CPU 缺失前帧和计数异常会留空，横轴为采样序列。曲线保留 240 帧且不跨程序重启；用户文本仍为 ASCII 安全显示。
